### Token (lexer.h)

```c
typedef enum {
    TOK_WORD,       // Command or argument word
    TOK_PIPE,       // |
    TOK_REDIR_IN,   // <
    TOK_REDIR_OUT,  // >
    TOK_REDIR_APP,  // >>
    TOK_HEREDOC,    // <<
    TOK_SEMI,       // ;
    TOK_AND,        // &&
    TOK_OR,         // ||
    TOK_BG,         // &
    TOK_EOF         // End of input
} TokenType;

typedef struct {
    TokenType type;
    char *value;    // Dynamically allocated string (NULL for operators)
    int quoted;     // 1 if from quoted string (suppresses glob)
} Token;

typedef struct {
    Token *tokens;  // Dynamic array of tokens
    int count;      // Number of tokens
    int capacity;   // Allocated capacity
} TokenList;
```

### AstNode (ast.h)

```c
typedef enum {
    NODE_COMMAND,       // Simple command: argv + redirects
    NODE_PIPELINE,      // cmd1 | cmd2 | cmd3
    NODE_LIST,          // pipeline ; pipeline && pipeline || pipeline
    NODE_IF,            // if/elif/else/fi
    NODE_WHILE,         // while/do/done
    NODE_UNTIL,         // until/do/done
    NODE_FOR,           // for/in/do/done
    NODE_FUNCTION_DEF,  // name() { body; }
    NODE_NOT,           // ! pipeline
    NODE_SUBSHELL       // ( list )
} AstNodeType;

typedef enum {
    LIST_SEP_SEMI,      // ;   (sequential)
    LIST_SEP_AND,       // &&  (conditional and)
    LIST_SEP_OR,        // ||  (conditional or)
    LIST_SEP_BG,        // &   (background)
    LIST_SEP_NONE       // end of list

typedef struct {
    struct AstNode *pipeline;
    ListSepType sep;
} ListEntry;

struct AstNode {
    AstNodeType type;
    union {
        struct { Command *cmd; } command;
        struct { AstNode **cmds; int cmd_count; int negated; } pipeline;
        struct { ListEntry *entries; int count; } list;

        struct { char *name; AstNode *body; } func_def;
        struct { AstNode *child; } not_clause;
        struct { AstNode *body; } subshell;
    } data;
};
```

## 5. lexer.c / lexer.h - Tokenizer

**Purpose**: Break raw input string into a list of typed tokens.

### lexer.h - Public Interface

```c
void tokenlist_init(TokenList *list);
void tokenlist_free(TokenList *list);
int lexer_tokenize(const char *input, TokenList *list,
                   char *error_buf, int error_buf_size);
const char *token_type_str(TokenType type);
```

### lexer.c - Internal

**State Machine States** (enum LexerState):
```c
STATE_START   // Between tokens, looking for next token start
STATE_WORD    // Accumulating a word (letters, digits, etc.)
STATE_SQUOTE  // Inside single quotes (everything literal)
STATE_DQUOTE  // Inside double quotes (escape sequences active)
```

**Key Function**: `lexer_tokenize()` (line 81-245)

Algorithm:
1. Start in `STATE_START`
2. Read each character:
   - **Whitespace** in START → skip
   - **Letter/digit** → enter STATE_WORD, accumulate in DynBuf
   - **`'`** → enter STATE_SQUOTE, set `was_quoted=1`
   - **`"`** → enter STATE_DQUOTE, set `was_quoted=1`
   - **Operators** (`|`, `&`, `<`, `>`, `;`) → emit operator token, check for doubles (`||`, `&&`, `>>`, `<<`)
   - **End of word** (whitespace/operator while in STATE_WORD) → emit TOK_WORD
3. Handle escape sequences in double quotes: `\"`, `\\`, `\$`, `` \` ``
4. Unclosed quotes → return error (-1)
5. Append TOK_EOF at the end

**Uses**: `DynBuf` for word accumulation (avoids fixed-size buffer overflow)


### parser.c - Internal

**Parser State**:
```c
typedef struct {
    TokenList *tokens;    // Input token list
    int pos;              // Current position in token list
    char *error;          // Error message buffer
    int error_size;       // Error buffer size
    ParseResult result;   // Current parse state (OK/ERROR/INCOMPLETE)
    int in_compound;      // Nesting depth (for INCOMPLETE vs ERROR)
} Parser;
```

**Helper Functions**:
```c
peek(p)           // Look at current token without consuming
advance(p)        // Consume current token, move to next
at_eof(p)         // Is current token EOF?
at_word(p, "if")  // Is current token a specific word?

is_keyword(word)  // Is word a shell keyword? (if, then, fi, while, ...)
at_list_end(p)    // Is current token a compound-command terminator?
```

**Parsing Functions** (each corresponds to a grammar rule):

| Function | Grammar Rule | What it produces |
|----------|-------------|-----------------|
| `parse_list()` | `and_or ((';'\|'&') and_or)*` | NODE_LIST (or single node) |
| `parse_and_or()` | `pipeline (('&&'\|'\|\|') pipeline)*` | NODE_LIST with AND/OR seps |
| `parse_pipeline()` | `['!'] command ('\|' command)*` | NODE_PIPELINE or NODE_NOT |
| `parse_command()` | dispatches to compound or simple | NODE_* (depends on keyword) |
| `parse_simple_command()` | `word+ (redirect)*` | NODE_COMMAND |
| `parse_if()` | `'if' list 'then' list ['elif'...]  ['else' list] 'fi'` | NODE_IF |
| `parse_while()` | `'while' list 'do' list 'done'` | NODE_WHILE |
| `parse_until()` | `'until' list 'do' list 'done'` | NODE_UNTIL |
| `parse_for()` | `'for' NAME ['in' word*] 'do' list 'done'` | NODE_FOR |
| `parse_brace_group()` | `'{' list '}'` | body list node |

**Function Definition Parsing** (inside `parse_command()`, line 466-507):
- Detects `name()` pattern (word ending in `()`)
- Strips the `()` suffix
- Parses `{ body }` brace group
- Returns NODE_FUNCTION_DEF

**PARSE_INCOMPLETE Logic**:
- `in_compound` is incremented when entering if/while/for/brace
- If EOF is hit while `in_compound > 0`, result is PARSE_INCOMPLETE
- This tells main.c to prompt for more input

**Arithmetic Evaluator** (recursive descent, operator precedence):

| Function | Precedence | Operators |
|----------|-----------|-----------|
| `arith_expr()` | Entry point | (delegates to additive) |
| `arith_additive()` | Low | `+`, `-` |
| `arith_multiplicative()` | Medium | `*`, `/`, `%` |
| `arith_power()` | High | `**` |
| `arith_unary()` | Higher | `-`, `+`, `~`, `!` (unary) |
| `arith_primary()` | Highest | Numbers, `$VAR`, `(expr)` |

**Variable Expansion Details** (`expand_variables`, line 229-372):
- `$VAR` → look up by name
- `${VAR}` → look up by name (brace-delimited)
- `$?` → last exit code
- `$$` → `getpid()`
- `$#` → positional parameter count
- `$@`, `$*` → all positional params
- `$1`-`$9` → individual positional params
- `$((expr))` → arithmetic evaluation
- `$(cmd)` → command substitution via callback

**Glob Expansion** (inside `expand_command`, line 445-491):
- Uses POSIX `glob()` function with `GLOB_NOCHECK | GLOB_TILDE`
- If pattern expands to multiple files, shifts argv array to make room
- Inserts all matches into argv
- Skips quoted args (`arg_quoted[i] == 1`)

### execute_simple_command Flow (line 183-361)

```
1. Check VAR=value assignment (no command) → var_set()
2. Clone command (don't modify AST)
3. Expand words (tilde, variables, globs)
4. Check if builtin that MUST run in parent (cd, export, unset, local) → run directly
5. Check break/continue → set counters, return
6. Check return → set flag, return
7. Check source/. → call source_file()
8. Check function table → push scope, set positional params, execute body, pop scope
9. Check non-capturing builtin → run directly
10. Create capture pipe if needed
11. fork()
    Child:
      - Reset signals (SIG_DFL)
      - Wire capture pipe to stdout
      - setup_redirects()
      - If builtin: builtin_execute() + _exit()
      - Else: execvp() (never returns on success)
      - On failure: print error + _exit(127)
    Parent:
      - Set fg_child_pid
      - Close write end of capture pipe
      - read() captured output from pipe
      - waitpid() for child
      - Reset fg_child_pid
```

### execute_pipeline_node Flow (line 367-505)

```
1. If only 1 command → use execute_simple_command (fast path)
2. Allocate (N-1) pipes + optional capture pipe
3. For each command i:
   a. fork()
   b. Child:
      - Reset signals
      - if i > 0: dup2(pipes[i-1][0], STDIN)      // read from previous pipe
      - if i < N-1: dup2(pipes[i][1], STDOUT)      // write to next pipe
      - if i == N-1 and capturing: dup2(cap_pipe[1], STDOUT)
      - Close ALL pipe fds
      - Expand command, setup redirects
      - execvp() or builtin_execute()
4. Parent closes all pipes
5. Read captured output from cap_pipe[0]
6. waitpid() for ALL children
7. Return last child's exit code
8. If pipeline negated (! prefix): invert result
```

### Internal Architecture

```c
static VarScope global_scope;              // Always exists
static VarScope *scope_stack[MAX_SCOPES];  // MAX_SCOPES = 32
```

### Lookup Order (`var_get`, line 93-127)

```
1. Positional parameters ($1-$9, $#, $@, $*)
2. Local scopes (innermost first, depth-1 down to 0)
3. Global scope
4. Environment (getenv())
```

### Scope Push/Pop (for functions)

```c

```

Used in executor.c when calling a shell function:

## 12. functions.c / functions.h - Shell Functions

**Purpose**: Store and retrieve user-defined shell functions.

### functions.h - Public Interface


### Internal Structure

```c
typedef struct {
    char *name;      // Function name
    AstNode *body;   // Cloned AST body
} ShellFunc;

static ShellFunc func_table[MAX_FUNCTIONS];  // MAX_FUNCTIONS = 128
static int func_count = 0;
```

### Key Details

- `func_define()` calls `ast_clone(body)` to deep-copy the AST. This is essential because the original AST is freed after the defining command completes.
- `func_undefine()` uses swap-and-decrement: replaces the removed entry with the last entry in the table (O(1) deletion).
- Function invocation happens in executor.c's `execute_simple_command()` - if `func_lookup()` returns non-NULL, the body is executed with a pushed scope.

```c
int jobs_count(void);                        // Number of active jobs
```

### Key System Calls

**`jobs_check()` (line 92-116)**:
```c
while ((pid = waitpid(-1, &status, WNOHANG | WUNTRACED)) > 0) {
    // WNOHANG: don't block if no child has changed state
    // WUNTRACED: also report stopped children
    // -1: wait for any child

    if (WIFEXITED(status))   → job state = DONE
    if (WIFSIGNALED(status)) → job state = DONE, exit = 128 + signal
    if (WIFSTOPPED(status))  → job state = STOPPED
}
```

**`job_foreground()` (line 118-152)**:
```c
if (job is STOPPED) {
    kill(-j->pgid, SIGCONT);  // Send SIGCONT to process group
    // Negative pgid = send to entire process group
}
waitpid(-j->pgid, &status, WUNTRACED);  // Wait for job
if (WIFSTOPPED(status)) → job stays in table as STOPPED
else → job marked DONE, reaped
```

**`job_background()` (line 154-168)**:
```c
if (job is STOPPED) {
    kill(-j->pgid, SIGCONT);  // Resume
    j->state = JOB_RUNNING;
    // Don't waitpid - let it run in background
}
```

## 14. test_builtin.c / test_builtin.h - Conditional Expressions

**Purpose**: Evaluate conditional expressions for `test` and `[` builtins.

### Public Interface

```c
int test_builtin_execute(int argc, char **argv);
// Returns 0 (true) or 1 (false)
```

### Supported Tests

**File tests** (using `stat()`, `lstat()`, `access()`):
- `-e file` → file exists
- `-f file` → is regular file
- `-d file` → is directory
- `-r file` → is readable
- `-w file` → is writable
- `-x file` → is executable
- `-s file` → is non-empty (size > 0)
- `-L file` → is symlink

**String tests**:
- `-n string` → string is non-empty
- `-z string` → string is empty
- `s1 = s2` → strings are equal
- `s1 != s2` → strings are not equal

**Numeric tests** (using `strtol()`):
- `n1 -eq n2` → equal
- `n1 -ne n2` → not equal
- `n1 -lt n2` → less than
- `n1 -le n2` → less than or equal
- `n1 -gt n2` → greater than
- `n1 -ge n2` → greater than or equal

**Logical operators**:
- `! expr` → negate
- `expr -a expr` → AND
- `expr -o expr` → OR

Uses a recursive descent evaluator (`eval_expr()` → `eval_primary()`).

## 15. util.c / util.h - Dynamic Buffer Utility

**Purpose**: Growable string buffer used throughout the codebase.

### Public Interface (util.h)

```c

    int cap;
```

- **main.c**: Multi-line input accumulation buffer
